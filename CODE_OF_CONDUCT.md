# Code of Conduct

Nezzel uses the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), incorporated here by reference, for project spaces and people representing the project.

Be respectful, accept constructive feedback, and welcome different backgrounds and experience levels. Harassment, threats, discriminatory abuse, sexual harassment, and publishing another person's private information are unacceptable. Maintainers apply the Covenant's correction, warning, temporary-ban and permanent-ban guidelines according to the circumstances, while protecting reporters' privacy.

**Private conduct reports:** email contact@hululsoft.mr. Do not post sensitive conduct reports in public issues.

Reference: Contributor Covenant 2.1 by the Contributor Covenant community; this file is a short project summary and reference, not a verbatim reproduction.
