Quick questions

Short answers, including what it sends and what it can’t download.

Is it really free?

Yes, and open source under AGPL-3.0. No ads, no account, no paid tier.

Why do I see a warning when I open it?

The beta is free and not yet signed by Apple or Microsoft. The warning is expected on Mac and Windows; the install page shows how to open it and how to check the file.

Does it send anything about me?

Crash and error reports and anonymous daily usage counts go to our own servers. Both are on by default, and each has a switch in Settings. Update checks go to GitHub. Never file names, paths, cookies or the full link, unless you send a report yourself with “Include the link” ticked.

When does it use my browser login?

Only when a site asks for one, and only after you say yes. It passes that site’s cookies to that download, and remembers the browser’s name, never the cookie values.

Where are my files?

In Downloads/Nezzel, or any folder you choose. Removing an item from the list never deletes the file.

A link doesn’t work?

Open an issue on GitHub and name the site. We don’t need the link itself.

What can’t it save?

Private posts, paid content and DRM-protected video aren’t supported.
