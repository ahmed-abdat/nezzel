Open Nezzel the first time

The beta is free and not yet signed by Apple or Microsoft, so Mac and Windows warn you the first time you open it. That’s expected, and you only need to allow it once.

MacWindowsLinux

Mac

  1. 1

    Open it, then click “Done”

    Drag Nezzel to Applications and open it. A message says Apple couldn’t verify it; click “Done”, not “Move to Trash”

  2. 2

    Open Privacy & Security

    Apple menu → System Settings → Privacy & Security, then scroll down to Security

  3. 3

    Click “Open Anyway”

    Next to the Nezzel line. Confirm with your password or Touch ID, then click “Open”. You usually won’t see the message again

On macOS 15 or later. On older versions: right-click the app and choose “Open”.

Or in Terminal, one command instead of the steps:

xattr -dr com.apple.quarantine /Applications/Nezzel.app

Windows

  1. 1

    Run the installer

    Open the file you downloaded. A blue screen may appear: “Windows protected your PC”

  2. 2

    Click “More info”

    The small link under the text. It shows the file name and “Unknown publisher”

  3. 3

    Click “Run anyway”

    Then finish the install. You usually won’t see the screen again for this version

Linux

  1. 1

    .deb package

    For Ubuntu, Debian and Mint: open it in your package manager, or use the terminal

  2. 2

    .rpm package

    For Fedora and openSUSE: open it in your package manager, or use the terminal

  3. 3

    Or the AppImage

    For any distribution: make the file executable, then run it

The Linux packages need glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36 and later).

Only download it from here

Only download Nezzel from the downloads section of this site. If you find it anywhere else, don’t install it. To check the file wasn’t changed, compare its SHA-256 hash with the one published with the release:

Mac
shasum -a 256 ~/Downloads/Nezzel_*.dmg
Windows
Get-FileHash .\Nezzel_*-setup.exe
Linux
sha256sum Nezzel*

Why the warning?

Apple and Microsoft charge for a signing certificate, and Nezzel is free. The beta builds aren’t signed yet. All the code is open on GitHub for anyone to review.
