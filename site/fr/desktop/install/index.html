Ouvrir Nezzel la première fois

La bêta est gratuite et pas encore signée par Apple ou Microsoft : Mac et Windows vous avertissent à la première ouverture. C’est normal, et il suffit de l’autoriser une fois.

MacWindowsLinux

Mac

  1. 1

    Ouvrez-le, puis cliquez sur « Terminé »

    Glissez Nezzel dans Applications et ouvrez-le. Un message indique qu’Apple n’a pas pu le vérifier : cliquez sur « Terminé », pas sur « Placer dans la corbeille »

  2. 2

    Ouvrez Confidentialité et sécurité

    Menu Pomme → Réglages Système → Confidentialité et sécurité, puis descendez jusqu’à Sécurité

  3. 3

    Cliquez sur « Ouvrir quand même »

    À côté de la ligne Nezzel. Confirmez avec votre mot de passe ou Touch ID, puis « Ouvrir ». Le message ne devrait pas revenir

Sur macOS 15 ou ultérieur. Sur les versions plus anciennes : clic droit sur l’application, puis « Ouvrir ».

Ou dans le Terminal, une commande remplace les étapes :

xattr -dr com.apple.quarantine /Applications/Nezzel.app

Windows

  1. 1

    Lancez le programme d’installation

    Ouvrez le fichier téléchargé. Un écran bleu peut s’afficher : « Windows a protégé votre ordinateur »

  2. 2

    Cliquez sur « Informations complémentaires »

    Le petit lien sous le texte. Il affiche le nom du fichier et « Éditeur inconnu »

  3. 3

    Cliquez sur « Exécuter quand même »

    Puis terminez l’installation. L’écran ne devrait pas revenir pour cette version

Linux

  1. 1

    Paquet .deb

    Pour Ubuntu, Debian et Mint : ouvrez-le dans votre gestionnaire de paquets, ou au terminal

  2. 2

    Paquet .rpm

    Pour Fedora et openSUSE : ouvrez-le dans votre gestionnaire de paquets, ou au terminal

  3. 3

    Ou l’AppImage

    Pour toutes les distributions : rendez le fichier exécutable, puis lancez-le

Les paquets Linux demandent glibc 2.35 ou plus récent (Ubuntu 22.04, Debian 12, Fedora 36 et versions ultérieures).

Téléchargez-le uniquement ici

Téléchargez Nezzel uniquement depuis la section de téléchargement de ce site. Si vous le trouvez ailleurs, ne l’installez pas. Pour vérifier que le fichier n’a pas été modifié, comparez son empreinte SHA-256 avec celle publiée avec la version :

Mac
shasum -a 256 ~/Downloads/Nezzel_*.dmg
Windows
Get-FileHash .\Nezzel_*-setup.exe
Linux
sha256sum Nezzel*

Pourquoi cet avertissement ?

Apple et Microsoft facturent un certificat de signature, et Nezzel est gratuit. Les versions bêta ne sont pas encore signées. Tout le code est ouvert sur GitHub.
